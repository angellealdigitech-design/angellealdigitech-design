## 🛠️ Stack Técnico y Herramientas

* **Sistemas Operativos:** Linux CLI (Debian, Ubuntu Server), Windows Server (Active Directory DS, GPOs, DNS, DHCP, permisos NTFS).
* **Redes & Telecomunicaciones:** Protocolos TCP/IP, direccionamiento IPv4/IPv6, subnetting VLSM, VLANs (802.1Q), enrutamiento estático/dinámico, Cisco Packet Tracer, Wireshark.
* **Seguridad & Almacenamiento:** Listas de Control de Acceso (ACLs estándar y extendidas), VPN IPsec punto a punto, cortafuegos (iptables, UFW), esquemas RAID y estrategias de copia de seguridad.
* **Servicios de Red:** Servidores DNS (BIND9), servidores web (Apache, Nginx), streaming de audio (Icecast2, Ices2), transferencias seguras SFTP/SSH.
* **Virtualización:** VMware Workstation/ESXi, Oracle VirtualBox (configuración EFI / VBoxManage).
* **Bases de Datos & Web:** MySQL, MariaDB (consultas DDL/DML, modelos E/R), despliegues LAMP y administración de CMS.
