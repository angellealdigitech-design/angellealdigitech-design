### 📚 Competencias y Proyectos por Asignaturas (ASIR)

#### 🌐 Planificación y Administración de Redes
- **Diseño de Topologías:** Implementación de esquemas de red LAN/WAN jerárquicos sobre Cisco Packet Tracer, cálculo y direccionamiento VLSM en IPv4 e integración con IPv6.
- **Conmutación y Segmentación:** Configuración de switches Cisco Catalyst (VLANs, enlaces troncales 802.1Q, VTP, STP y routing inter-VLAN).
- **Enrutamiento:** Configuración de rutas estáticas, enrutamiento por políticas y protocolos dinámicos (RIPv2, OSPF) entre routers Cisco.

#### 🛡️ Seguridad y Alta Disponibilidad
- **Seguridad Perimetral y Acceso:** Creación y aplicación de Listas de Control de Acceso (ACLs estándar y extendidas) para filtrado de tráfico, despliegue de túneles VPN para interconexión segura de sedes y filtrado con `iptables` y `UFW`.
- **Laboratorio de Análisis de Red y Ataques MITM:** Prácticas de auditoría interna con Kali Linux y Windows 10 para estudio de envenenamiento de tablas ARP (`arpspoof`, `dsniff`), captura e inspección de paquetes con `Wireshark` y aplicación de contramedidas de mitigación.
- **Alta Disponibilidad y Respaldo:** Bastionado básico de sistemas operativos, niveles RAID y diseño de políticas de copias de seguridad e integridad de datos.

#### 🖥️ Administración de Sistemas Operativos
- **Sistemas Linux (Ubuntu Server / Debian):** Administración completa mediante CLI, jerarquía del sistema de archivos, gestión de usuarios, grupos y permisos avanzados (chmod, chown, SUID/SGID), administración de almacenamiento (particionado, LVM) y scripting en Bash para automatización de tareas programadas (cronjobs).
- **Windows Server:** Instalación y configuración de controladores de dominio (Active Directory DS), estructura de Unidades Organizativas (OUs), despliegue de políticas de grupo (GPOs) para securización de puestos y gestión de permisos NTFS y recursos compartidos.

#### 🌍 Servicios de Red e Internet
- **Servicios de Infraestructura:** Despliegue y mantenimiento de servidores DHCP (concesiones, reservas, ámbitos) y servidores de nombres DNS (zonas directas e inversas, reenvíos).
- **Servidores de Aplicación y Acceso Remoto:** Puesta en marcha de servidores web (Apache y Nginx), servidores de transferencia de archivos seguros (FTP/SFTP) y túneles SSH para administración remota cifrada.

#### 🗄️ Gestión de Bases de Datos
- **Diseño Relacional:** Análisis de requisitos, modelado entidad-relación, normalización y definición de esquemas de bases de datos.
- **Motor MySQL / MariaDB:** Redacción e implementación de consultas SQL (DDL, DML), control de accesos por roles y privilegios de usuario, exportación/importación y estrategias de backup/restore.

#### ☁️ Implantación de Aplicaciones Web
- **Despliegue de Entornos:** Montaje y configuración de pilas LAMP (Linux, Apache, MySQL, PHP) y WAMP para soporte de aplicaciones web.
- **Gestores de Contenidos y Front-end Técnico:** Instalación y mantenimiento de CMS (WordPress), integración básica de componentes web (HTML5, CSS, scripts JS de interactividad) y administración del entorno de ejecución.
